# 微信公众号解读页手机适配设计

## 背景
- 目标页面为 `output/article_analysis/index.html` 及各账号详情页。
- 当前页面主要面向桌面浏览器，手机宽度下存在可读性、点击区域、信息密度和长文本换行体验不足的问题。

## 目标
- 在常见手机浏览器宽度下消除横向滚动。
- 提升目录页和账号页的可读性与触控体验。
- 保持现有抓取、重解读和静态页生成逻辑不变。

## 范围
- 修改静态 HTML 生成逻辑中的共享样式与少量结构输出。
- 覆盖目录页、账号详情页、最新文章区、历史文章折叠区、操作按钮区。
- 不改接口协议、不新增后端路由、不调整解读业务逻辑。

## 方案
- 增加标准移动端 `viewport`，保证页面按设备宽度渲染。
- 将固定宽度页面改为更适合手机的流式布局，缩小边距并优化纵向节奏。
- 目录页将胶囊式链接改为手机友好的块级卡片/列表呈现，长标题允许换行。
- 抓取与重解读操作区在窄屏下改为纵向堆叠或自适应两列，提升点击面积。
- 总结正文、列表、图片和长文本统一增加换行与溢出保护。
- 历史文章区域保留折叠交互，但优化留白、字号和边框层级，减少手机端噪音。

## 设计细节

### 目录页
- 标题、副标题、操作区在手机下纵向排列。
- `directory-list` 从横向 wrap 为主改成单列优先的块布局。
- 每个账号入口显示为独立卡片，账号名、篇数、最新时间、标题分层展示。
- “立即抓取”按钮在手机端使用全宽样式，状态文案换到下一行。

### 账号页
- 最新文章区作为主卡片增强，标题、时间、按钮和总结形成稳定纵向信息流。
- 两个重解读按钮在手机端纵向排列，保留桌面端并排展示能力。
- 总结段落行距、列表缩进、分节标题间距统一放大，提升长文阅读舒适度。
- 历史文章 `details/summary` 点击区增大，避免窄屏误触。

### 通用规则
- 图片最大宽度 100%，二维码和插图不溢出容器。
- 长链接、英文、模型输出长段落启用断行策略。
- 统一按钮高度、圆角、间距和状态色，避免手机端视觉拥挤。

## 风险与取舍
- 只做轻量 HTML 微调，不重构模板结构，降低回归风险。
- 不新增复杂 JS 交互，优先依赖 CSS 媒体查询完成适配。
- 个别旧页面若内容字段异常，最多影响排版细节，不影响主流程功能。

## 验证
- 本地生成并检查目录页与多个账号页在手机宽度下的展示。
- 重点验证：
  - 无横向滚动
  - 按钮易点
  - 长标题和长总结不溢出
  - 目录页与账号页信息层级清晰
- 回归测试至少覆盖 `tests/test_article_analysis.py` 中与 HTML 生成相关的用例。
